## Template Frasi per Guida Utente

### Aggiungere Attività
- `aggiungi [descrizione attività]`
- `aggiungi [descrizione attività] [data/ora]`
- `aggiungi [descrizione attività] alla mia lista [lavoro/personale]`
- `aggiungi [urgente/alta priorità/bassa priorità] [descrizione attività]`

### Aggiornare Attività
- `aggiorna [nome attività]`
- `segna [nome attività] come fatto`
- `aggiorna [nome attività] a [stato/priorità/data]`

### Eliminare Attività
- `elimina [nome attività]`
- `elimina tutte le attività [completate/in corso/da fare]`
- `elimina tutte le attività [di lavoro/personali]`

### Consultare Attività
- `cosa ho per [oggi/domani/questa settimana]`
- `mostrami attività [di lavoro/personali]`
- `dimmi attività [alta priorità/urgenti]`
