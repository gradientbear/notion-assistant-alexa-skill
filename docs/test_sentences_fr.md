## Templates de Phrases pour Guide Utilisateur

### Ajouter une Tâche
- `ajouter [description tâche]`
- `ajouter [description tâche] [date/heure]`
- `ajouter [description tâche] à ma liste [travail/personnelle]`
- `ajouter [urgent/haute priorité/basse priorité] [description tâche]`

### Mettre à Jour une Tâche
- `mettre à jour [nom tâche]`
- `marquer [nom tâche] comme terminé`
- `mettre à jour [nom tâche] à [état/priorité/date]`

### Supprimer une Tâche
- `supprimer [nom tâche]`
- `supprimer toutes les tâches [terminées/en cours/à faire]`
- `supprimer toutes les tâches [de travail/personnelles]`

### Consulter les Tâches
- `qu'est-ce que j'ai pour [aujourd'hui/demain/cette semaine]`
- `montre-moi tâches [de travail/personnelles]`
- `dis-moi tâches [haute priorité/urgentes]`
